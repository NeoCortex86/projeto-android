# 🤖 História do Mascote do Android

Site de teste inicial, experiência própria.

Projeto desenvolvido durante o curso de *HTML5 e CSS3* do [Curso em Vídeo](https://cursoemvideo.com), com o objetivo de praticar a criação de páginas responsivas e semânticas.

🔗 *[Clique aqui para acessar o site no ar!](https://github.io)*

---

## 🛠️ Tecnologias utilizadas
- *HTML5:* Estruturação semântica (header, nav, main, article, aside, footer).
- *CSS3:* Estilização com degradês, variáveis, fontes externas (@font-face) e responsividade.

## ✨ O que eu aprendi neste projeto
- Adaptar imagens diferentes para celular e computador usando a tag <picture>.
- Tornar vídeos incorporados do YouTube responsivos em qualquer tamanho de tela.
- Publicar um site gratuitamente na internet usando o *GitHub Pages*.
